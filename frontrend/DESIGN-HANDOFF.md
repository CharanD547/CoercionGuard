# CoercionGuard opening and consent lab

[Local build](http://127.0.0.1:8002/) · [Apple AirPods Pro](https://www.apple.com/airpods-pro/) · [Nike Air Max Dn](https://about.nike.com/en/newsroom/releases/nike-air-max-dn-official-images)

Apple was the primary reference for revealing a technical detail at close range. Nike's newsroom release was the secondary reference for product-first framing. Both pages loaded and scrolled at 1440 × 900 in Chromium. The consent form, timing, and camera sequence are original to CoercionGuard.

| Trigger | Change and end state | Interruption |
| --- | --- | --- |
| First visit | Static HTML displays the title, entry button, and stacked paper while the 3D bundle loads. At 950 ms the renewal copy slides out. At 2.1 s the authorization layer enters. | The entry button is available throughout. The flat paper remains usable if the 3D bundle fails. |
| Open consent lab | The same exhibit moves to its lab slot over 600 ms. The term selector and proposal checker become available. | Escape, reduced motion, and resize can settle the handoff immediately. |
| Select a term or drag the exhibit | The corresponding paper copy slides out, or the form turns to show its layers. | The latest input replaces the previous animation target. The term buttons expose the same evidence by keyboard. |
| Replay intro | The opening returns. Closing it restores focus to Replay intro. | Escape closes the opening. Reload in the same tab goes directly to the lab. |

## Assets and licenses

The exhibit geometry, textures, and fallback are generated by this project. The build uses Three.js 0.160.0 and Astro 7.4.12 under MIT licenses included with the packages. Archivo and Courier Prime load through Google Fonts and use the SIL Open Font License. Reference sites supplied visual direction only.

## Verification

- Astro production build and all 10 API tests passed. Chromium verified four verdicts and JSON exports, plus WebSocket results, findings, and screenshots in all three bundled comparisons.
- Chromium 159 on Windows 11 verified keyboard dismissal, focus recovery, resize during the handoff, and usable fallback with the 3D bundle blocked. Touch emulation at 320 × 568 and 390 × 667 verified entry and proposal checks without page overflow.
- Two desktop replay samples at 1440 × 900 on an Alienware 16 Area-51 with a Core Ultra 9 275HX used headless Chromium and SwiftShader. Animation callback intervals had a 16.7 ms median, an 83–100 ms 95th percentile, and 383–433 ms worst intervals. These measurements include software rendering.
- The optional Three.js chunk is about 659 KB before compression. Hardware-accelerated desktop pacing, physical phones, a direct 90/100 reference score, and a Vultr container deployment remain unverified.
